# 南京大学仙林校区校园巴士免费实时到站时间预测平台

在南京大学仙林校区等车时，打开网页就能查**东西线走哪条路、车到哪了、下一班还要等多久**。手机和电脑浏览器都能用，需要梯子，无需安装或登录。

**[打开校园巴士 · 查车和到站时间](https://nju-bus-eta.njubus.workers.dev/)**

每天 **07:00–22:15（北京时间）** 提供预测，车辆 GPS 从 **07:30** 开始更新。其中，每日夜间 **19:00–22:00** 期间，统计规律显示，南大门发车的车辆基本均沿西线运行，第十一餐厅的车辆则基本沿东线运行，实际在途车辆识别后会按定位更新。遇到临时调度，请留意校方通知和现场安排。

## 怎么查车

1. **选站点。** 点地图上的站名，也可以在「在这里等车」面板里通过站名下拉框选择。
2. **选方向。** 按你的目的地选择「往第十一餐厅」或「往南大门」。在南大门和第十一餐厅，准备上车时选驶往另一端的方向，面板会显示预计发车时间。「终点到站」用于查看驶入本站的车辆。
3. **看等待时间。** 「接下来的巴士」按线路列出最多三班，越靠前越快到达或发车。数字是还要等的分钟数，以 0.5 分钟为单位。页面保持在前台时约每 5 秒自动刷新，也可以点右上角手动刷新。

> **举例** 从菜根潭去第十一餐厅，先点「菜根潭」，再选「往第十一餐厅」，看西线的第一张卡片。如果显示「3.5 分」，就是预计约 3 分 30 秒后到站。

## 地图上还能做什么

| 功能 | 操作 |
| --- | --- |
| 查看车辆位置 | 地图用巴士图标显示车辆的最新 GPS 定位。可结合站点面板查看到站倒计时。 |
| 放大、拖动和复位 | 手机用双指缩放，电脑用滚轮，也可以点地图右侧的 `＋`、`－`。点「查看完整线路」按钮回到全图。 |
| 查看自己的位置 | 点地图右侧的准星，允许浏览器定位。落在校园底图范围内时会显示当前位置。定位是可选的，校外也能查车，个人位置由浏览器本地处理。 |
